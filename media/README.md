# 启动视频

小游戏背景音乐由 `src/music.mjs` 的原创曲谱通过 Web Audio 实时合成，不使用外部音乐文件。拼图「画廊慢时光」为 76 BPM 的柔和旋律与琶音；合成「池塘跳跳舞」为 108 BPM 的跳跃旋律与短和弦。每首八小节循环，低音、主旋律和泛音分层；默认独立音量 22%。音乐音符按音频时钟预排，停止时清除音符和计时器，退出时关闭 AudioContext。

`startup.mp4` 为用户提供的《风经过的地方》视频副本，1920×1080、24 fps、5.042 秒，包含音轨。

默认在插件载入时以 0.6 倍速播放约 8.4 秒，文字中轴位于屏幕宽度的 25%，每个字依次从轻微模糊和下移中淡入；最后 1.3 秒通过界面动画渐进模糊并淡出。保留原始视频编码，避免二次压缩；原视频音轨始终静音。

`startup-poster.jpg` 为原视频第一帧预览。设置中可以关闭片头、切换播放速度、重新预览。

`startup-piano.m4a` 为原创钢琴启动音，10.5 秒、44.1 kHz、双声道 AAC。Cmaj9 → Fmaj9 → Gsus2 → Cmaj9 的轻柔琶音，原声钢琴与少量大厅混响。从乐句起点按正常音高播放，不按视频进度跳过起音，以 1.1 秒 S 形包络平滑淡入；界面开始退出时在 1.3 秒内渐弱，关闭片头后立即释放播放资源。钢琴声默认开启；浏览器拦截播音时可点击「播放钢琴声」，也可在设置中单独关闭。

钢琴渲染脚本：`scripts/render-startup-piano.swift`。渲染后将峰值调整为 0.55、添加 35 毫秒淡入和 1.4 秒尾部淡出，编码为约 128 kbps AAC。

`pet-laugh.mp3` 为用户选定的大笑音频，15.696 秒、48 kHz、单声道 MP3；从公开表情库下载后未作修改。来源和许可边界见 `NOTICE.md`。

`pet-laugh-frames.png` 为用户 GIF 的原像素帧图集（10 列 × 8 行，单帧 224×224）。`pet-laugh-animation.json` 保存全部 80 帧的原时长、源文件哈希和播放片段位置。图集本身保留原白底，Canvas 逐帧渲染时仅清除连接到帧边缘的白色区域，封闭的白牙会保留。待机显示第 0 帧；点击从第 32 帧的起笑动作开始，约 500 毫秒后播放笑声；随后循环第 40–79 帧，直到笑声结束。

`reaction-*.gif` 为用户提供的十张云朵表情原文件副本，保留原尺寸、帧数和时序。`reactions.json` 记录各自源文件名和 SHA-256。九张为动画，`reaction-141.gif` 原文件为单帧。点击奶蛙唤起信息气泡，点击信息气泡随机展示原 GIF，再次点击表情直接收起；闲置 6 秒自动隐藏。鼠标经过或焦点变化不会唤起气泡。

桌宠大笑中再次点击会同时暂停笑声、取消尚未触发的 500 毫秒播音计时及后续回调，并立刻显示待机帧。
